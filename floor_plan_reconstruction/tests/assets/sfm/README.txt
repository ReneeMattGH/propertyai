These six real, overlapping photographs are used only as a test fixture for the
COLMAP structure-from-motion stage. They were resized to 1024 px for repository
size.

Source: Hugging Face dataset "alexmkwizu/colmap-testing-dataset"
(https://huggingface.co/datasets/alexmkwizu/colmap-testing-dataset), south-building
sample set. They are not used by the application at runtime and are never served
as a reconstruction result.
